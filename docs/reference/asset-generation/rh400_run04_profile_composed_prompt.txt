## PROMPT

```
Generate a single RH-400 Regolith Harvester Rover for GalaxyGame, a hard-sci-fi industrial space settlement simulation game.

SUBJECT:
A Mk2 autonomous regolith harvesting rover — a heavy-duty mobile industrial vehicle designed to skim planetary surfaces and gather regolith for in-situ resource utilization (ISRU) processing. The vehicle has a low-profile rectangular chassis with a forward-mounted regolith skimming scoop, a mid-body cylindrical processing canister, a rear-mounted dust exhaust stack, a top-mounted sensor mast with rotating array, and six visible drive wheels on an independent suspension chassis. Exposed hydraulic actuator arms connect the scoop to the chassis at the joints.

PROPORTIONS (visual anchors — canonical dimensions: length 6.80m, width 3.30m, height 2.65m):

- Width remains substantially narrower than overall length
- Body height remains low relative to footprint

STYLE (resolved from grounded_industrial_v1 profile):
- Clean white or light-gray primary paneling over dark gray to black mechanical undercarriage

MANUFACTURING (resolved from earth_factory_v1 profile):

OUTPUT:
```

## HOW THIS PROMPT DIFFERS FROM RUN 03 (Control)

### Change 1: Feature Ordering (Primary → Secondary → Tertiary)

**Run 03**: Flat numbered list with equal weight ("all must be clearly visible")
```
RECOGNITION FEATURES (all must be clearly visible):
1. Six-wheel independent suspension chassis
2. Forward regolith skimming scoop assembly
3. Mid-body cylindrical processing canister
4. Rear-mounted dust exhaust stack
5. Top-mounted sensor mast with rotating array
6. Exposed hydraulic actuator arms
```

**Run 04**: Priority-tier ordered from Visual Definition's `visual_priority` field
```
RECOGNITION FEATURES (ordered by priority tier from Visual Definition visual_priority):

PRIMARY (must be dominant in the render):
1. Six-wheel independent suspension chassis
2. Forward regolith skimming scoop assembly

SECONDARY (must be clearly visible):
3. Mid-body cylindrical processing canister
4. Top-mounted sensor mast with rotating array

TERTIARY (should be present and visible upon closer inspection):
5. Rear-mounted dust exhaust stack
6. Exposed hydraulic actuator arms
```

**Rationale**: Run 03 evaluation showed both generators dropped features 3-6 while retaining features 1-2. This suggests positional bias — early-listed features receive more attention. Priority tiers explicitly signal importance to the generator.

### Change 2: Proportion Instruction (Visual Anchors)

**Run 03**: Numeric ratio
```
PROPORTIONS (must be accurate):
- The vehicle is significantly longer than it is wide or tall — approximately 2.6 times longer than wide
```

**Run 04**: Visual anchors + canonical dimensions preserved as authoritative data
```
PROPORTIONS (visual anchors — canonical dimensions: length 6.80m, width 3.30m, height 2.65m):
- Elongated low-slung vehicle — length clearly exceeds width
- Width remains substantially narrower than overall length
- Body height remains low relative to footprint
```

**Rationale**: Run 03 evaluation showed both generators ignored the numeric ratio (produced ~1.7-2.0:1 instead of specified ~2.6:1). Visual anchors use comparative language that image generators can process more effectively than abstract numbers. Canonical dimensions are preserved as authoritative data, not replaced.

### Change 3: Style/Manufacturing from Resolved Profiles

**Run 03**: Inlined prose from multiple documents
```
MANUFACTURING APPEARANCE (Mk2 — Precision Industrial Factory):
- Primary paneling: clean white or light-gray over the main body panels
- Mechanical undercarriage: dark gray to black chassis...
- Surface finish: precision-machined surfaces...
- Tech level Mk2 characteristics: cleaner than early-generation equipment...
```

**Run 04**: Resolved from structured profiles with explicit source attribution
```
STYLE (resolved from grounded_industrial_v1 profile):
- Clean white or light-gray primary paneling over dark gray to black mechanical undercarriage
- Precision-machined surfaces with minimal visible construction seams
- NASA/ESA-inspired aerospace-industrial aesthetic

MANUFACTURING (resolved from earth_factory_v1 profile):
- Precision industrial factory assembly — not frontier, bootstrap, or improvised
- Materials: high-strength aerospace steel structural members...

TECHNOLOGY LEVEL (resolved from tl2_v1 profile):
- Mk2 characteristics: cleaner than early-generation equipment, fewer visible fasteners, welded joints...
```

**Rationale**: Separating style, manufacturing, and technology level into independent sections prevents them from competing for attention within a single "manufacturing appearance" block. Each section is self-contained with clear source attribution.

### Change 4: Hazard Markings Elevated to Its Own Section

**Run 03**: Buried within the MANUFACTURING APPEARANCE block
```
MANUFACTURING APPEARANCE (Mk2 — Precision Industrial Factory):
...
- Black and yellow hazard striping applied functionally to moving parts and edges only
```

**Run 04**: Separate section between Technology Level and Recognition Features
```
MARKINGS (from grounded_industrial_v1 profile):
- Black and yellow hazard striping applied functionally to moving parts and edges only (scoop edges, exhaust stack rim)
- Unit identification stenciled on the hull (simple alphanumeric marking)
```

**Rationale**: Run 03 evaluation showed hazard markings were completely absent from both generators. This was likely because they were buried within the manufacturing block and deprioritized against other features. A separate section elevates their visibility in the prompt structure.
