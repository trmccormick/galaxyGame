# Generating Star Systems

## Overview

The game includes a rake task to programmatically generate new star systems outside of automatic spawning (e.g., when wormholes open). Generated systems are saved as JSON files in `data/json-data/generated_star_systems/` for use by the game engine.

## Quick Start

Generate 5 star systems with default parameters (1 star, 10 planets each):

```bash
docker compose exec app bundle exec rake starsim:generate_systems[5]
```

## Available Rake Tasks

### `starsim:generate_systems`

Generate multiple star systems and save them to `data/json-data/generated_star_systems/`.

**Usage:**
```bash
docker compose exec app bundle exec rake starsim:generate_systems[count,planets_per_system,stars_per_system]
```

**Parameters:**
- `count` (default: 1) - Number of systems to generate
- `planets_per_system` (default: 10) - Terrestrial planets per system
- `stars_per_system` (default: 1) - Number of stars per system

**Examples:**

Generate 10 single-star systems with 5 planets each:
```bash
docker compose exec app bundle exec rake starsim:generate_systems[10,5,1]
```

Generate 3 binary star systems with 15 planets each:
```bash
docker compose exec app bundle exec rake starsim:generate_systems[3,15,2]
```

Generate a single system (minimum viable):
```bash
docker compose exec app bundle exec rake starsim:generate_systems[1]
```

**Output:**

### `starsim:clear_systems`

Delete all generated star systems (requires confirmation).

**Usage:**
```bash
docker compose exec app bundle exec rake starsim:clear_systems
```

The task will display all files to be deleted and ask for confirmation:
```
⚠️  About to delete 5 generated system file(s)

  • proc-2026110_202611202309.json
  • proc-2026110_202611202310.json
  • ...

Are you sure? (yes/no): yes
✅ Deleted 5 system file(s)
```

## System Generation Details

### What Gets Generated

Each generated system contains:

- **System Metadata**: Name, identifier, solar system data
- **Stars**: One or more stellar objects with:
  - Stellar classification (spectral type)
  - Mass, radius, temperature
  - Habitable zone parameters
- **Planets**: Terrestrial planets with:
  - Mass, radius, density, gravity
  - Atmosphere composition and pressure
  - Hydrosphere coverage
  - Geological and biosphere attributes
  - Orbital parameters (semi-major axis, eccentricity, orbital period)
  - Moons (procedurally generated)
- **Miscellaneous Bodies**: Asteroids, gas giants, ice giants (varies by system)

### Generation Strategy

The `StarSim::ProceduralGenerator` uses a **hybrid approach**:

1. **~40% Template-Based**: Uses curated alien world templates for realistic terraformable planets
2. **~60% Procedural**: Generates diverse, procedurally-unique planets using 4X-balanced heuristics

This ensures playable variety while maintaining scientific plausibility.

### File Naming Convention

Generated systems follow this naming convention:
```
<IDENTIFIER>_<TIMESTAMP>.json
```

Example:
```
proc-2026110_20261120_230952.json
```

The identifier is generated by the `NameGeneratorService` and timestamp ensures uniqueness.

## Integration with Game Systems

### Loading Generated Systems

Generated systems can be:
1. **Loaded dynamically** by the game engine when referenced
2. **Indexed** into the game's star system catalog
3. **Used for settlements** as procedurally-generated expansion targets

### Automatic System Generation

The game also automatically generates systems when:
- **Wormhole events** open to new locations
- **Procedural expansion** is triggered by player actions
- **Economic simulation** spawns new trade routes

For automatic generation, you don't need to run this task; the game handles it internally.

## Troubleshooting

### "No generated systems directory found"

The directory doesn't exist yet. Run any `starsim:generate_systems` task to create it:
```bash
docker compose exec app bundle exec rake starsim:generate_systems[1]
```

### Generation is slow

Generation complexity scales with system size:
- Increase `planets_per_system` → slower
- Increase `stars_per_system` → slower

For testing, use small counts:
```bash
docker compose exec app bundle exec rake starsim:generate_systems[1,3,1]
```

### Invalid parameters

All parameters must be positive integers:
- ✅ `starsim:generate_systems[5,10,2]` → Valid
- ❌ `starsim:generate_systems[0,10,2]` → Invalid (count must be ≥ 1)
- ❌ `starsim:generate_systems[5,-1,2]` → Invalid (planets must be ≥ 1)
